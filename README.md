## Featured project

### [Muhasabah · محاسبة](https://github.com/MohammadRayan1/muhasabah)
**A tuition tracker for teachers of Islamic classes.** [Live app →](https://muhsabah.netlify.app)

<a href="https://github.com/MohammadRayan1/muhasabah"><img src="https://raw.githubusercontent.com/MohammadRayan1/muhasabah/main/docs/screenshots/dashboard.png" alt="Muhasabah dashboard" width="720"></a>

- Billing on the 1st, with prorated first bills for mid-month joiners
- Parent self sign-up through one-time links, with teacher approval
- Families, WhatsApp/text/email reminders, and printable receipts
- Quran memorization tracking (sabaq, sabqi, manzil) that parents can see
- Optional Stripe card payments, recorded by a signed webhook

`React Router 7` `TypeScript` `PostgreSQL` `Prisma` `Tailwind CSS` `Netlify` `Stripe`
